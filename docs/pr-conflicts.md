# 기존 드라이버와 PR의 충돌 검증

2026-10-18 재검증. PR 테스트 통과는 해당 구현을 재현한다는 뜻이며,
사용자 기기에 대한 정확성을 증명하지 않는다. 기존 실측과 충돌하는 부분은
원본 캡처를 다시 읽고 기존 구현·PR·수정본을 비교했다.

### F24VDD 실제 반례 (KST)

| 시각 | 프레임 | 16비트 값 | PR 값 |
|---|---|---:|---:|
| 10-09 19:53:12.612 | CD | 1728 Wh | 192 Wh |
| 10-09 19:58:14.198 | CD | 1836 Wh | 44 Wh |
| 10-09 20:54:50.827 | BD | 1941 Wh | 149 Wh |
| 10-09 20:55:05.474 | 일반 EC | 1941 Wh | PR은 이 34-byte 상태 형식을 처리하지 않음 |

당시 사용자가 확인한 앱 완료 표시 **1.94 kWh**는 1941 Wh와 표시 정밀도에서
일치한다. 149 Wh와는 일치하지 않는다. PR의 80/218/221 Wh 테스트는 모두
256 미만이어서 잘못된 폭을 검출하지 못했다.

## 회귀 검증의 구분

- PR wire vectors: 같은 설정에서 명령 바이트가 일치하는지 검사한다. 기존 원격
  시작 조건은 별도로 유지하므로, 명령 비교 테스트에는 원격 허용을 사전 조건으로
  명시했다. 부정 테스트에서는 비허용 상태의 기존 명령 및 신규 alias 모두 거부한다.
- 사용자 캡처: 세탁기 일반 상태/진단 112개를 수신 순서대로 재생해 각 energy를
  확인한다. 정수기는 13개 보고를 재생해 910 mL, 슬롯 전환 및 0 교체를 확인한다.
- 합성 경계 테스트: 기존 34-byte payload에 두 tail bytes를 붙인 경우 공통 필드와
  시작 preset·자동 resume이 유지되는지 검사한다. 이를 새 실기기 캡처로 표시하지 않는다.

신규 기기와 추가 read-only 상태의 PR 기반 검증은 기존 사용자 기기에서의 새로운
실측 검증과 구분한다. 특히 신규 살균/필터 상태의 비영 전환, AIR mode 이름 등은
독립적인 조작·앱 비교가 추가로 필요하다.
